# 开发说明

## 现有功能

- 左侧导航：词书、复习、统计
- 词书：考点词、答案词、话题词，支持选组、继续学习和毛玻璃模式弹窗
- 词条：练习与速刷模式，错词自动进入复习
- 复习：词书和时间多选筛选、导出、每组数量、模式设置、详情抽屉、混合词类复习
- 统计：近 7 天趋势与鼠标提示

## 代码地图

`assets/app.js` 中主要包含：

- 演示数据与全局状态
- 页面视图切换和导航
- 词组、模式选择、练习流程
- 错词筛选、设置、导出和详情抽屉
- 统计图表与工具提示

## 建议的下一步重构

1. 将 `app.js` 按 `books`、`practice`、`review`、`stats` 拆分为 ES Modules。
2. 将演示数据替换为 API 请求，统一使用 `docs/DATA-CONTRACT.md` 的字段。
3. 将浏览器语音合成替换为可管理的真人发音资源 URL。
4. 增加登录、用户学习进度和服务端错词同步。
5. 导出 PDF/Word 建议改为服务端生成，CSV 可继续在前端完成。

## 上线前检查

- 三类词书的选组、继续学习、返回路径
- 从复习入口进入后的混合词类和返回复习逻辑
- 错词自动入库和筛选条件
- 音频资源、导出文件与日期时区
