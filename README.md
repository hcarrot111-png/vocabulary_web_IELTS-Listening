# 听力词汇练习网页端

这是可交给开发人员继续开发的完整前端工程包，不是只有一个 HTML 的演示包。

## 目录

- `index.html`：工程入口与页面结构
- `assets/styles.css`：页面样式和响应式布局
- `assets/app.js`：词书、复习、统计与交互逻辑
- `preview/index.html`：不需安装依赖的单文件预览版
- `tests/smoke-check.js`：核心文件与功能入口冒烟检查
- `docs/DEVELOPMENT.md`：开发与上线说明
- `docs/DATA-CONTRACT.md`：后续接口化所需的数据结构

## 本地运行

需要 Node.js 18 或更高版本。

```bash
npm install
npm run dev
```

打开 `http://localhost:4173`。

## 检查

```bash
npm test
node --check assets/app.js
```

## 直接预览

双击 `preview/index.html` 即可查看当前完整 Demo。实际开发请修改根目录的 `index.html` 和 `assets/` 中的源码。

## 当前版本

- 话题词词义速记中，“查看解析”展示完整答案信息，“确认答案”不展开解析，“再听一遍”重置当前词条。
- 答案词与话题词的中文例句按主词条对应中文高亮；考点词同替选项按实际数量居中排列。
- 考点词同替练习按同替数量自动生成 3 个或 5 个选项，并在解析中高亮主词条、同替及对应中文。
- 话题词词义速记每题固定为 3 个选项。
- 复习详情展示答案词难度，以及话题词难度与所属话题。
- 网页词表已替换为《听力 C11-21考点词-答案词-话题词.xlsx》中的有效记录。
- 答案词两种练习均显示词汇难度；话题词两种练习均显示话题与词汇难度。
- 答案词首次拼写错误后，允许修改错误字母并再次确认。
- 首次错误反馈阶段提供“再次确认”和“查看答案”，尚不展示答案与双语例句。
- 答案页根据“显示释义”设置去重：此前已显示释义时不重复追加，关闭时显示一次。

## 部署

这是静态前端工程。将整个工程上传到静态站点服务，并将发布目录设为工程根目录即可；首页是 `index.html`。

> 当前为前端 Demo，数据保存在浏览器本地。多用户、账号同步、真实语音资源和服务端导出需后续接入 API。
